# Software-Engineering-Project-DP-Map
This is the project hub for our Discovery Park Mapplication for software engineering. 

Our project is currently being hosted in arcGIS since UNT students are supplied with access to arcGIS online and pro. The map has been created and filled out and the website is currently being built there. This is because the website has direct access and integration support for heavy engineering based maps. 

Several folders will be created here to help document some of our code. 

We have not utilized a lot of programming language other than SQL for this project since the map is based on a very large dataset with all the needed information/fields. Currently, our plan is to document specific SQL queries we use for filtering various things within the application. This way, if we accidentally delete or remove a field, we are able to get the website fixed quickly. This also gives other groups and the instructor more information about how our project operates. 

Navigation will have to be custom coded separately. We are currently exploring options for this since it has been much more difficult than we initially thought. Once navigation is at a state we feel comfortable sharing (ie working), it will be uploaded here for documentation.
